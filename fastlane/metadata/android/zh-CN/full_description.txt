一款实验性的、基于 Chromium 的安卓网页浏览器，支持浏览器扩展，基于 Helium 与 Vanadium 构建。支持 Manifest V2（MV2）扩展。

你可以从以下来源安装扩展：
- Chrome 网上应用店（推荐）
- Opera 扩展中心
- Microsoft Edge 扩展中心

你也可以在内置的「Helium 安卓扩展」的选项页面中，通过本地 CRX（或 ZIP）文件进行安装。此外，你还可以手动加载未打包的扩展用于测试：进入「chrome://extensions」，开启「开发者模式」，选择「加载已解压的扩展程序」，并在存储访问框架（SAF）选择器中选中包含扩展的文件夹。加载扩展可能需要稍等片刻。

使用扩展
- 如需在隐身（OTR）模式下运行某个扩展，请前往「管理扩展程序」，找到该扩展，选择「详情」，然后打开「允许在隐身模式下运行」。
- 如需使用扩展的弹出窗口，请打开扩展菜单，点击扩展旁边的菜单按钮 ⋮，从列表中选择「固定到工具栏」。之后即可通过扩展专属的工具栏图标打开弹出窗口。
- 如需使用外部下载管理器、增强型深色模式以及更多隐私选项等高级功能，可以使用内置的「Helium 安卓扩展」。

调试地址
- 如需查看和访问调试地址，请使用「chrome://chrome-urls」。如需「实验性功能」，请使用「chrome://flags」。

WebRTC IP 策略
- 该选项位于「设置」→「隐私和安全」→「隐私」下的「WebRTC IP 处理方式」。如果你因 IP 默认被屏蔽而遇到 WebRTC 相关问题（例如 Discord 语音），可尝试将其改为「仅默认公共接口」，或「默认」。

注意：所有构建版本均为实验性质，可能会出现意外问题。本浏览器仅在可行范围内尽力提升安全性与隐私保护。若需在安卓上获得更好的保护，建议使用 GrapheneOS 配合 Vanadium，后者还集成了对 Android 系统 WebView 的补丁，并在系统层面提供了显著的內核与内存管理加固。
